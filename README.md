# UmaFightTactics

Fan-made game project repository.

## Character reference image assets

Character reference images under `public/assets/characters/race/` are synchronized from the public UmaRefs reference page (`https://umarefs.crd.co/`) by an automated workflow.

- Source filenames are preserved when available (for example `SpecialWeek-Race.png`).
- `public/assets/characters/race/manifest.json` records character-to-file mappings, source links, dimensions, size and SHA-256.
- Entries marked incomplete on UmaRefs are kept in the manifest without forcing a missing download.
- NPC and outfit references are intentionally excluded from this character image set.

UmaRefs states that it is not affiliated with Cygames. This repository likewise does not claim ownership of third-party reference artwork/assets; review the applicable rights and permissions before redistribution or public release.
