검토 기준: 실제 스킬 설명과 원화 4프레임의 준비·발동·후속 동작·회수를 대조. 템플릿 분류만으로 통과시키지 않았다. 자동으로 전파되는 공간 이펙트는 캐릭터의 몸동작과 구분했다.
