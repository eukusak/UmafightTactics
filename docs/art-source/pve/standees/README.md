# PvE 생성 원화와 런타임 기물

내장 이미지 생성기로 훈련 허수아비, 트랙 골렘, 보급 로봇, 트로피 수호자, 대형 트로피 수호자를 각각 생성했다. `prompts.json`은 실제 생성 지시이며 이 폴더의 PNG는 수정하지 않은 생성 원본이다.

`scripts/import-pve-art.py`가 실제 알파 경계를 잘라 최대 384×384로 축소하고 512×512 캔버스의 y=440에 발을 맞춘다. 게임 파일은 `public/assets/pve/standees/`, 원본/게임 이미지 SHA256과 크롭 좌표는 `src/data/manual/generated-pve.json`에 보존한다. `scripts/review-pve-art.py`로 다시 검증할 수 있다.

전투에서 기존 PvE 시트보다 새 전신을 우선 로드한다. 기존 Phaser 메시 기반 호흡·이동·공격·스킬·사망 모션을 적용하며 Canvas 렌더러에서는 이미지 변형을 사용한다. **부위별 리깅 또는 실제 Cubism Live2D 모델이 아니다.** 기존 시트와 프레임은 보존하고, 신규 전신 5개를 캐릭터 전투 시트 완료 수에 더하지 않는다.

실제 Live2D 제작에는 각각 가려진 부분까지 그린 레이어 원화와 Cubism Editor에서의 메시·디포머·모션 제작 및 내보내기가 남아 있다. 피격 동작은 추가하지 않았다.
