# 스킬별 이미지 프레임 애니메이션

2026-09-08 사용자 요청에 따라 부위 리깅을 중단하고 생성한 포즈를 PNG 스프라이트 시트로 재생하는 방식으로 변경했다. Cubism 모델이나 런타임 관절 조립이 필요하지 않다.

## 현재 제작 범위

- 초상화: 145/145명 완료.
- 새 모션 시트: 캐릭터 145/145명, PvE 5/5종. 남은 0명은 검수·등록 전까지 완료 수에 넣지 않는다. 진행 상태는 frame-sheets.json 및 개별 제작 명세를 기준으로 한다.
- 한 기물당 24개 포즈: 대기, 이동, 기본 공격, 스킬, 쓰러짐, 승리 각 4프레임. 이전 46프레임 시트와 별도 형식이다.
- `src/data/manual/frame-sheets.json`에 등록한 시트부터 전투와 모션 미리보기에서 사용한다. 없는 캐릭터는 기존 전신/초상화로 표시하며 완료 수에 넣지 않는다.

## 캐릭터마다 실제 스킬을 반영

`npm run art:briefs`가 145명과 PvE 5종의 실제 스킬 ID, 설명, 대상 규칙, 효과, 사거리, 스킬 해시와 제작 상태를 [개별 제작 명세](art-source/motions/briefs.json)에 기록한다. 템플릿별 포즈 초안만으로 검수 완료를 판정하지 않는다. 각 캐릭터의 `-Race.png` 의상·머리·장식을 참고하고 실제 효과에 맞는 포즈를 별도로 생성한다. 스킬 데이터가 바뀌면 해시 검사가 실패하여 재검수가 필요하다.

스페셜 위크는 사거리 3의 원거리 기본 공격과 `DASH_LINE` 직선 돌파를 사용한다. 공격은 손짓 발사, 스킬은 웅크린 출발→전방 발진→낮은 돌파→착지로 제작했다. 스킬 수정 과정에서 바뀐 무관한 쓰러짐/승리 행은 앞서 검수한 원본 행을 유지했다.

PvE 5종의 현재 스킬은 모두 마법 광역 반격이다. 허수아비의 장갑, 골렘의 바위 팔, 보급 로봇의 집게, 트로피 수호자의 방패/왕관을 유지한 개별 동작을 사용한다. 로봇에 치유를 추가하거나 방패 외형을 무적 효과로 해석하지 않는다. 투사체와 광역 이펙트는 엔진의 대상과 VFX 이벤트가 그린다.

## 제작·재생 계약

내장 imagegen으로 생성한 원본, 알파 처리 결과와 프롬프트는 `docs/art-source/motions/batch-01/`에 보존한다. `scripts/package-motion-frames.py`는 생성된 알파를 유지한 채 크롭·균일 축소·배치만 수행한다. 배경 제거를 코드로 하지 않는다. 원본 해시, 프레임별 크롭, 배율과 출력 해시는 각 `packing.json`에 기록한다.

런타임은 512×768 RGBA, 4열×6행, 셀 128×128, 접지 기준 (64,110)이다. 동일 기물의 24개 프레임은 같은 배율을 사용한다. 그림 자체를 다시 리깅/회전/변형하지 않는다. 이동 좌표는 기존 보드 보간이 결정한다.

기본 공격의 3번째 포즈는 실제 `releaseAt`에 도달한다. 피격은 모션을 초기화하지 않는다. 스킬의 준비 포즈는 미리보기에서 볼 수 있으며, 전투에서는 즉시 판정되는 `CAST` 시각에 방출 포즈부터 재생한다. 테이오·보드카 등 3연타는 `skillReleaseFrame: 0`으로 첫 발사부터 세 발사 포즈와 회복을 모두 재생한다. 피해 판정 시각은 기존 엔진을 유지하며 엔진에 없는 시전 지연을 추가하지 않는다. 쓰러짐은 마지막 포즈에서 멈추고 사망 페이드가 적용된다.

메인 메뉴의 **기물 모션 미리보기**에서 캐릭터별 스킬 설명, 6종 모션, 정지/시간 이동, 방향 반전, 2배속, 28기 표시 및 Canvas 렌더러를 확인할 수 있다. 4프레임은 제작 속도를 위한 초기 밀도이며 고프레임 애니메이션의 부드러움과 같지는 않다. 재생 프레임 수 증가와 연결 포즈 보정은 개별 검수를 거쳐 진행한다.

검증: 프레임 범위/공격 발사 동기화/스킬 변경 감지/PNG 규격·출처 검사, 타입 검사, 테스트, 린트, 빌드. TFT 동일성은 별도 [공개 규칙 대조 보고서](TFT_PARITY_AUDIT.md)이며 자체 테스트 통과가 동일성 통과를 뜻하지 않는다.

## 144명 추가 제작

첫 묶음: 사일런스 스즈카, 토카이 테이오, 마루젠스키, 후지 키세키, 오구리 캡, 골드 쉽, 보드카, 다이와 스칼렛, 타이키 셔틀, 그래스 원더. 각 원본 Race 참고 이미지, 생성 프롬프트, 알파 원본, 보정 이력, 스킬별 수동 검수는 `art-source/motions/production-144/<id>/`에 보존한다. `scripts/import-reviewed-motion.py <id>...`는 검수 기록과 현재 스킬 해시를 확인하고 실제 알파를 유지한 채 개별 시트를 포장한다. 반투명 머리카락·이펙트도 프레임 경계 계산에 포함한다. 옆 프레임으로 넘어간 장식 이펙트는 이미지 생성 도구로 제거하고 원화 자세는 유지했다.

두 번째 묶음: 히시 아마존, 메지로 맥퀸, 엘 콘도르 파사, 티엠 오페라 오, 나리타 브라이언, 심볼리 루돌프, 에어 그루브, 아그네스 디지털, 세이운 스카이, 타마모 크로스. 범위 기절 명령, 아군 전체 강화, 체력이 낮은 아군 회복, 자기 보호막·도발, 동일 대상 3연타, 직선 돌파를 각 캐릭터의 실제 효과와 의상에 맞춰 검수했다.

세 번째 묶음: 파인 모션, 비와 하야히데, 마야노 탑건, 미호노 부르봉, 메지로 라이언, 히시 아케보노, 유키노 비진, 라이스 샤워, 아이네스 후진, 아그네스 타키온. 이 묶음부터 원화의 부유 이펙트를 제외해 프레임 간 간섭을 줄였다. 실제 타깃 이펙트는 전투 엔진이 그리며 몸동작은 각 스킬의 돌진·방출·강화·도발·연사를 표현한다.
