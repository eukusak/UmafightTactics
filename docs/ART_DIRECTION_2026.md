# 2026-09-07 아트 방향 및 구현 상태

사용자의 최신 지시가 기존 `ART_REQUEST.md`의 도트 스타일보다 우선한다.
목표는 TFT의 판타지 아레나와 우마무스메의 경마 학원 분위기, 현대 포켓몬 게임을 연상시키는 매끈한 셀 셰이딩이다. 남색·청록 패널, 금색 주요 행동, 따뜻한 아이보리 글자, 입체적인 테두리와 부드러운 그림자를 사용한다. 기존 발주서의 파일명, 셀 크기, 행·열, 앵커, 프레임 수는 유지한다.

현재 구현은 React + Phaser의 **2D 렌더링에 원근감과 애니메이션을 적용한 2.5D 표현**이다. 실제 3D 모델이나 Live2D Cubism 리깅은 포함하지 않는다.

규격 통과는 파일 크기·PNG·알파 채널 검사를 뜻하며 모든 자산의 런타임 사용을 뜻하지 않는다. 아이콘은 상점/아이템/특성/증강에 연결했다. 스킬 VFX는 CAST 이벤트에 연결했다. 별 등급 VFX는 합성 완료 알림에 연결했고, 전투 기록의 상태 아이콘도 연결했다. UI 아틀라스와 일부 배너·능력치 상태 아이콘은 아직 모두 연결된 것은 아니다.

`STRICT_ART=1` 검수는 누락 298건(P0 128 / P1 170)으로 실패해야 정상이다. 일반 검수의 성공을 전체 납품 완료로 해석하지 않는다.

## 화면과 전투

- 타이틀, 메인 메뉴, 도감, 상점, 벤치, HUD, 특성/아이템 패널, 드래프트, 증강 선택, 결과 화면의 색·타이포·계층·프레임을 변경했다. 한글 폰트를 앱에 포함했다.
- 준비 보드와 전투 보드는 같은 원근 좌표를 사용한다. 배치한 앞열/뒷열이 전투 진입 때 뒤집히지 않는다.
- 전투 객체를 재사용하고 기록된 프레임 사이의 위치를 보간한다. 공격/스킬/피격/사망/부활/승리 상태를 기록 이벤트에서 재생한다. 피해 수치는 실제 ATTACK 피해량을 사용한다.
- 배속 변경은 전투를 처음부터 재시작하지 않는다. 피해량 표시 설정을 적용한다.
- PvE는 훈련장, PvP는 스테이지에 따라 주간/야간/더트 배경을 사용한다. 이는 장식이며 지형 효과나 특성 판정을 바꾸지 않는다.
- 캐릭터 시트가 없으면 참고 썸네일을 사용한다. 썸네일의 상하 이동은 최종 캐릭터 애니메이션을 대체하지 않는다.

## 캐릭터 제작 및 잘라 쓰기

`docs/art-source/character-production-plan.json`에 145명의 정확한 ID, 참고 Race 파일, 스킬 템플릿, 스킬명, 키 포즈 지시, VFX, P0/P1 우선순위를 기록했다. 동일한 스킬 템플릿의 키 포즈 지시는 공유하며, 캐릭터별 최종 원화/세부 동작 검토는 아직 필요하다. `samson_big`, `genuine`은 정확히 일치하는 Race 참고 파일이 없다.

스페셜 위크 시트의 내장 생성/투명화 재시도는 RGB 체크무늬 배경과 잘못된 포즈 개수를 반환했다. 첫 실패 샘플은 `docs/art-source/special_week_rejected_rgb.png`에 남겼다. 이를 RGBA로 형식만 바꾸거나 빈 프레임을 복제해 납품하지 않았다.

실제 투명 10×6 시트를 검토한 뒤 다음과 같이 가져온다.

```bash
python3 -m pip install -r requirements-art.txt
python3 scripts/slice-character-sheet.py special_week /absolute/reviewed-sheet.png
python3 scripts/build-system-art.py
```

출력은 `public/assets/characters/<unitId>.png`와 `public/assets/characters/frames/<unitId>/<clip>/00.png`, `animation.json`이다. 프레임마다 원래 셀 좌표를 유지하여 흔들림을 방지한다. 128×128 셀, 앵커 (64,110), idle 6 / run 8 / basic_attack 8 / skill_cast 10 / hit 4 / ko 6 / victory 8의 총 50프레임이다. 실제 포즈의 자연스러움과 앵커 정렬은 별도 육안 검수가 필요하다.

가져오기는 RGB, 불투명 배경, 잘못된 격자, 비어 있는 필수 프레임, 여백 셀의 그림, 셀 경계에 닿는 그림을 거부한다. 기존 납품 폴더를 덮어쓰지 않는다. 초상화/컷인은 별도 발주 규격에 맞춰 제작해야 한다.

## 재생성과 검증

- `scripts/build-system-art.py`: 시스템 아이콘, VFX, UI, PvE 생성 및 전달 자산 목록 갱신. 벡터 아이콘 원본은 `public/assets/system_vectors/`에 있다.
- `scripts/build-reference-previews.py`: Race 이미지의 정면 얼굴 썸네일 143개를 재생성한다. 출처 SHA와 미리보기 상태를 별도 목록에 기록하며 최종 납품으로 세지 않는다.
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`로 코드 검증.
- `node --import tsx scripts/check-art-manifest.ts`는 `npm run check:art`와 동일한 검수 코드다. 현재 실행 환경의 tsx CLI IPC 제한 때문에 이 호출법을 사용했다.
- Chromium 1440×810 및 1366×768에서 타이틀→메뉴→매치 생성→드래프트→배치→전투→4배속→결과를 실행하고 콘솔 오류 0건을 확인했다. 1366×768 도감에서도 깨진 이미지 0건을 확인했다. 캡처는 `docs/screenshots/`에 있다. 기존 114개 테스트와 신규 재생 계약 테스트 3개가 통과했다.

배경 생성은 내장 이미지 도구를 사용했으며 API/CLI 대체 생성은 사용하지 않았다. 배경의 공통 프롬프트와 장면별 지시는 `art-source/background-prompts.md`에 정리했다.
