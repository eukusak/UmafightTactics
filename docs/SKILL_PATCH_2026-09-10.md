# 캐릭터 스킬 패치 · 2026-09-10

PR #12의 아이템 패치에 추가. 기존 24종 변형을 42개 전투 패턴으로 재구성하고 145명 모두에게 명시적인 스킬 프로필, 대표 경기, 수치·준비 시간·색상·문양을 부여했다. 145개의 서로 다른 엔진을 만들었다는 뜻은 아니다.

## 실패 원인

GitHub Actions 작업 102856671349의 controls.spec.ts는 강화 편자 방어력 +20을 기대했으나 아이템 패치는 +15였다. 기대값과 남아 있던 이전 공격력 설명·아이템 이름을 교정했다. 검사 생략이나 기준 완화 없이 전체 브라우저 검사를 실행한다.

## 경기 출처와 선정

- UmaRogue pr0의 고정 커밋 b53aab53a96626187bc9877dacd4a0cab5d94275, data_pipeline/source/uma_rogue_jpn.sqlite3. Git blob e0aee26ca7353d897e96a8da8bd16c277428eef6. 전체 6,413행을 조회해 145명 모두 경기 근거 확보.
- 재현: 해당 SQLite 파일을 별도로 받은 뒤 python scripts/skills/extract-race-evidence.py <sqlite 경로>. 파일 해시를 먼저 검증한다. 원본 DB는 이 PR에 재배포하지 않으며 선정 근거는 src/data/manual/race-evidence.json에 보관한다.
- 대표 경기 21명은 복귀전·대표적 성과를 수동 선정. 나머지는 확인된 승리의 등급, 상금, 최근 날짜 순으로 선택. 승리가 없는 하루 우라라는 실제 최고 성적 2위로 표시한다.
- 타이키 셔틀의 자크 르 마루아상, 엘 콘도르 파사의 생클루 대상, 스테이 골드의 홍콩 경기는 이 스냅샷에서 찾지 못해 다른 확인 가능한 경기로 대체했다.
- 원본 grade 열이 일부 GII/GIII를 GI로 표기하므로 경기명에 명시된 등급을 우선하여 가중치를 계산한다.
- 거리 교정은 최소 3승, 등급 가중치 55% 이상인 후보 중 12건만 채택했다. 역사적 스타일·역할 전체를 통계만으로 교체하지 않았다. 시즌별 신규 선발에서 남은 표본이 많은 특성을 먼저 분산하여 S5 중거리 과밀을 해결했다.

## TFT 자료의 활용

사용자가 제공한 5개 텍스트를 설계 참고로 사용했다. 세트 3~5 자료는 일부 기물 목록이므로 전체 시즌을 모두 검증했다고 주장하지 않는다. 현재 TFT와 완전히 동일한 게임이라는 판정도 아니다.

| 자료 | 참고 동작 | 적용 예 |
|---|---|---|
| 세트 1 | 왕복 피해, 연쇄, 고립, 흡혈 범위 | 왕복 궤도, 연쇄 섬광, 고립 결정타, 흡수 휩쓸기 |
| 세트 2 | 확장 폭발, 연결 보호막, 침묵 구역 | 확장 폭발, 연결 등불, 침묵 지대 |
| 세트 3 | 정화·회복, 관통 구속, 지속 광선 | 정화 선율, 관통 구속, 지속 광선 |
| 세트 4 | 집중 후 폭발, 다단 기술, 능력 약화 | 집중 유성, 삼단 결정타, 주력 저격 |

광역 최대 대상 수, 지속 시간, 피해 및 회복 계수는 UFT 전투 크기에 맞춰 조정했다. 연쇄는 동일 대상 재타격 금지, 피해 흡수는 실제 체력 손실만 반영, 처치 환급은 해당 타격의 처치에만 적용한다.

## 프레임과 이펙트

기존 PNG 몸동작은 유지한다. 준비·발동·회수 포즈를 실제 스킬 타임라인에 맞춰 재생하며 단발/연타/집중을 구분한다. 직선·부채꼴·연쇄는 실제 피격 대상 좌표를 사용하고 각 기물의 색상·보조색·문양을 추가한다. 새로운 145세트의 그림을 생성한 작업은 아니다.

스페셜 위크, 사일런스 스즈카, 토카이 테이오, 라이스 샤워 원화 시트를 육안 확인했다. 전체 145명의 원래 몸동작 유형 및 주 대상 규칙은 자동 대조했고, 원본 이미지/프레임 해시는 그대로 검증한다. 자세한 기록은 docs/art-source/motions/skill-choreography-review.json.
