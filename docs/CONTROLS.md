# 전투 화면 조작 및 상세 정보

- 기물을 상점 카드 영역 어디에나 드래그하면 판매합니다. 끄는 동안 기물 이름과 실제 판매 금액을 표시하며, 장착 장비는 보관함으로 돌아갑니다. 아이템 보관함이 가득 차거나 전투 중인 필드 기물이면 판매를 거절합니다.
- 기물 클릭/우클릭은 오른쪽 상세 정보를 엽니다. 다른 기물을 클릭하면 정보를 바꾸며 자동 교환하지 않습니다. 빈 필드/대기석 클릭은 선택한 기물을 이동합니다. 점유 칸 교환은 드래그로 합니다.
- 기본 키: D 새로고침, F 경험치, E 마우스로 가리킨 기물(없으면 선택한 기물) 판매, W 필드/대기석 이동, 1/3 정찰, Space 내 편성, Tab 전투 통계. Esc는 배치 선택 취소 → 상세 정보 닫기 → 설정 순서로 처리합니다.
- 영문 물리 키를 인식하므로 한글 IME·Caps Lock 상태에서도 조작합니다. 설정에서 변경한 키도 적용하며 입력창·텍스트 편집, Ctrl/Alt/Meta 조합, 길게 누르기 반복 입력은 게임 명령을 실행하지 않습니다. 드래프트·증강·결과창에서는 상점/필드 단축키를 차단합니다. 공동 선택 경기장에서는 방향키로 캐릭터를 움직입니다.
- 기물 정보: 별 등급, 코스트, 역할, 특성, 체력, 마나, 공격력, 주문력, 방어력, 마법저항력, 공속, 사거리, 치명타, 스킬, 장착 아이템, 판매 버튼. 준비 중에는 별/장비 반영 기본 능력치를 표시하고 전투 중에는 현재 재생 프레임의 효과 반영 능력치를 표시합니다. 체력/마나/장비를 미리 계산된 미래 결과에서 가져오지 않습니다.
- 필드 전투 중에도 아군·적군 기물을 클릭할 수 있습니다. 정찰 편성의 기물도 조회 가능합니다. 타인 기물에는 판매 버튼이 없습니다.
- 특성 클릭: 설명, 현재 배치 수, 각 단계 효과, 활성 단계, 이번 시즌 보유 기물 목록. 동일 기물은 한 번만 세고 대기석은 제외합니다.
- 재료 아이템 클릭: 효과와 모든 조합(재료당 10종). 완성품/추가 재료를 클릭하여 설명과 역조합식을 탐색할 수 있습니다. 조합 목록은 실제 엔진 레시피를 읽습니다.
- 온라인 판매/배치/구매는 기존 서버 명령으로 전송하며 UI가 골드나 소유권을 먼저 바꾸지 않습니다.

## 회전 공동 선택 · 캐릭터 모션 · 효과음

- 9개 기물이 트랙을 회전합니다. 바닥 좌클릭/우클릭 또는 방향키로 내 트레이너를 이동합니다. 기물을 클릭하면 그 기물을 따라갑니다. 클릭 즉시 지급하지 않으며 먼저 닿은 트레이너가 가져갑니다.
- 1-1은 2.5초 대기 후 전원 출발합니다. 이후 공동 선택은 체력이 낮은 순으로 2명씩 4.5초 간격으로 출발합니다. 출발 전에도 이동 목표를 지정할 수 있습니다.
- 각 트레이너는 한 번만 획득합니다. 재료는 보관함, 기물은 대기석으로 들어갑니다. 재료 보관함이 가득 찼으면 획득 기물이 재료를 장착해 유실을 방지합니다.
- 출발 후 12초 안에 획득하지 않으면 자동으로 이동해 남은 기물을 선택합니다. AI와 접속이 끊긴 참가자도 같은 이동·접촉 판정을 따릅니다.
- 온라인은 서버가 50ms 단위로 이동·접촉을 판정하고 100ms 간격으로 상태를 공유합니다. 개인 저장과 서버 재시작 모두 진행 중인 위치·출발 시간·획득 기록을 보존합니다.
- 준비 필드는 전투와 같은 캐릭터 시트의 4프레임 대기 모션을 재생합니다. 초상화는 상점·대기석·정보 조회에 사용합니다.
- 제공된 `select.mp3`는 버튼 선택, `level-up.mp3`는 성공한 4G 경험치 구매에 사용합니다. 경험치 버튼과 F 키 모두 지원하며 실패·중복 온라인 구매에서는 레벨업 효과음이 나지 않습니다.

## 검증

`npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.
`npm run test:ui`는 기존 시즌 검사와 함께 1920×1080 / 1366×768에서 판매, 키보드, 정보창, 아이템 조합 및 전투 조회를 검사합니다. 공동 선택의 실제 마우스/방향키 조작, 대기 모션 프레임 변화, 두 MP3의 브라우저 디코딩도 검사합니다.
