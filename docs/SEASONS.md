# 다섯 시즌의 아레나

새 게임에서 시즌 카드를 선택하거나 온라인 방을 만들 때 시즌을 지정한다. 한 매치의 모든 참가자와 AI는 같은 시즌을 사용한다. 시즌 변경은 새 매치에서만 가능하다. 도감의 시즌·시너지 필터와 기물 상세 정보에서 출전 여부를 확인할 수 있다.

## 출전 원칙

- 시즌마다 서로 다른 기물 60명. 전체 145명 모두 최소 한 시즌에 출전한다.
- 시즌 1의 기존 출전 명단은 유지한다. 나머지 네 시즌에는 미출전 기물을 나눠 배정하며 중복 출전도 허용한다.
- 코스트별 기물 수는 모든 시즌이 14 / 14 / 13 / 11 / 8명이다. 공유 풀·상점 확률·성장 규칙은 동일하다.
- 현재 5코스트 기물이 8명이므로 5코스트 8명은 모든 시즌에 등장한다. 코스트·역할·스킬·초상화·모션은 캐릭터별로 유지하고 시즌 특성만 달라진다.
- 기존 특성 24종은 캐릭터가 보유한 대로 유지한다. 시즌 전용 특성은 각각 4종, 총 20종이다. 전용 특성당 15명을 배정하며 서로 다른 기물 3 / 5 / 7명일 때 최고 도달 단계 하나가 적용된다.
- 전용 특성의 효과는 해당 특성을 가진 기물 자신에게 적용된다. 같은 기물의 중복 배치는 특성 수를 늘리지 않는다. 시즌 전용 엠블럼은 제공하지 않는다.
- 명단은 미출전 할당량과 코스트·역할·기존 특성 분포를 함께 고려해 결정론적으로 생성한다. 시즌 설정은 전역 변수가 아닌 매치에 저장되어 서로 다른 온라인 방이 섞이지 않는다.

## 구현과 재현

- `src/game/engine/seasons/catalog.ts`: 시즌 주제, 20개 특성의 효과와 배분 규칙.
- `src/data/generated/seasons.json`: `npm run data:build`로 생성하는 전체 명단과 특성 배정.
- `src/game/engine/roster/index.ts`: 시즌별 기물·코스트·특성 조회. 기존 `ACTIVE_*`는 S1 호환용이며 실제 매치 경로는 시즌 조회를 사용한다.
- 시즌 ID는 생성, 공유 풀, 플레이어, 상점, 드래프트, 증강체 보상, AI 구매, 전투 입력, 도감, 저장·복원, 서버 로비에 전달된다.
- `scripts/season-icons.ts`는 시즌 색상과 도형으로 SVG 엠블럼 20개를 생성한다. 기존 PNG 캐릭터·스킬 아트는 재사용한다.
- 준비 화면의 특성 수는 실제 보드의 기물만 센다. AI의 구매 평가는 배치 예정 팀을 기준으로 한다.
- 현재 로스터 호환성 해시: `e4ea4debfadc7400`. 시즌 명단과 특성 효과도 해시에 포함하므로 이전 버전의 저장은 새 게임으로 시작해야 한다.
