# 144명 추가 모션 제작 검수

첫 묶음 10명 / 240포즈를 추가했다. 전체 캐릭터 11/145명, PvE 5/5종이다. 나머지 134명은 제작·검수 중이며 미등록 원화는 완료로 집계하지 않는다.

- 전체 150개 테스트, 타입 검사, 린트 통과.
- 번들 Node 24.19.0 Vite 프로덕션 빌드 통과. 기존 큰 번들 경고는 유지된다.
- 최종 시트 포장 뒤 프레임·스킬 해시·PNG 출처 검사 4개 재통과.
- 아트 380/514, 규격 오류 0; 누락 134는 남은 캐릭터 모션이다.
- 24포즈의 원본 의상·실제 스킬·투명 알파·프레임 경계를 수동 검수했다. 보드카·다이와 스칼렛·타이키 셔틀·마루젠스키의 옆 프레임으로 넘친 효과는 내장 이미지 도구로 보정했다. 코드는 생성된 알파를 유지하며 크롭·축소·배치만 한다.
- Chromium 미리보기에서 보드카의 동일 대상 연속 발사 프레임을 확인했다.
- TFT 동일성 판정은 기존 보고서의 NOT_IDENTICAL이며, 모션 추가가 동일성 통과를 의미하지 않는다.

## 두 번째 10명

누적 추가 20/144명, 전체 캐릭터 21/145명, 480개 새 포즈. 각 24포즈의 생성·알파 원본과 최종 512×768 시트를 시각 검수했으며 프레임·출처·스킬 해시 테스트 4개를 재통과했다. 이 묶음은 재생 코드 변경 없이 기존 레지스트리에 등록한다.

## 세 번째 10명

누적 추가 30/144명, 전체 캐릭터 31/145명, 720개 새 포즈. 원본 의상·스킬별 자세·알파 원본·최종 24프레임 시트를 검수했다. 원화에서 부유 이펙트를 제외하고 캐릭터 동작에 집중했다.

## 네 번째 묶음: 새 모션 누적 40/144명

어드마이어 베가부터 시킹 더 펄까지 10명. 원본 Race 의상과 실제 스킬을 대조하여 생성·알파 처리하고 240개 포즈를 시각 검수했다. 시킹 더 펄은 같은 대상에 세 번 발사하며, 사쿠라 바쿠신 오는 아군 전체 버프다. 512×768 RGBA 시트와 크롭/해시 기록을 등록했다. 캐릭터 전체 41/145명, 남은 104명.
