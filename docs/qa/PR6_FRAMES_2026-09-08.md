# PR6 스킬별 프레임 방식 전환 검증

- 사용자 요청: 부위 리깅을 중단하고 공격·이동·각자의 스킬을 이미지 프레임으로 제작.
- 초상화 145/145. 새 24프레임 시트는 캐릭터 1/145(스페셜 위크), PvE 5/5. 남은 캐릭터 144명은 개별 제작 명세만 생성했으며 원화 완료로 세지 않는다.
- `npm run art:briefs`: 150개 명세, 검수 시트 6, 대기 144. 실제 스킬 JSON 해시가 변경되면 검수 테스트가 실패한다.
- `npm test`: 12개 파일, **150개 테스트 통과**. 최종 시트 보정 후 프레임 테스트 4개 재통과.
- TypeScript 및 ESLint 통과. 프로덕션 Vite 빌드는 번들 Node **24.19.0**에서 통과(13.50초). PATH의 Node 24.13.0은 108개 모듈 변환 뒤 종료 코드 1 또는 Windows 0xC0000409로 종료했으며 JS 오류 메시지가 없었다. Node 24.19로 같은 소스/의존성을 빌드하여 통과했다. 시스템 Node 설치나 전역 설정은 변경하지 않았다.
- 아트 검사 **370/514**, 규격 오류 0. 누락 144는 캐릭터 전투 시트. 신규 24프레임 형식을 이전 46프레임 형식으로 집계하지 않는다.
- 생성 PNG의 실제 투명 알파 검사, 포즈별 크롭/접지점/원본 및 출력 해시 기록. 옆 프레임으로 돌출한 초기 시트는 imagegen으로 간격을 보정한 후 다시 포장했다.
- Chromium 1280×720: 스페셜 위크 직선 돌파 정지 프레임, PvE 공격/스킬, 28기 Canvas 표시 확인. 프레임 이동 버튼과 일시정지 동작 확인. 뷰어 경고/오류 로그 0.
- 새 프레임 방식의 별도 전체 실제 매치 화면 검수는 아직 추가하지 않았다. 기존 전투/온라인 회귀 테스트 및 본 PR의 앞선 PvE 매치 검수와 구분한다.
- TFT 공개 규칙 대조: **일치 4 / 차이 11 / 미검증 4**, `NOT_IDENTICAL`. 엄격 모드는 예상대로 종료 코드 1. 항목마다 인용한 패치 버전이 다르며 최신 전체 명세와의 완전 동일성 검증이 아니다.
