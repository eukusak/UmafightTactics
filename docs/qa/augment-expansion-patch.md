## 증강 등급 순서

- 전체 특성 44종에 이동속도 능력치 보너스가 남아 있지 않음을 검사한다.

## AI

사용자가 제공한 전략/팁에서 경제 구간, 조합 전환, 리롤 타이밍, 아이템 및 경쟁 상대 확인을 반영했다. 학습 모델을 훈련한 것이 아니라 기존 규칙 기반 AI의 공개 정보 평가를 개선했다.

- 증강을 무작위로 고르던 동작을 보드·아이템·체력·단계·보유 복사본·공개 경쟁자 기반 점수로 교체.
- 전용 증강을 받은 캐릭터를 구매/배치 계획에 포함. 회복·마나 지원 전용 증강은 공격 캐리로 오인하지 않도록 역할을 구분한다. 후반 1~2코스트 1~5장뿐인 신규 전용 증강은 감점.
- 7~8장 모인 캐리이며 경쟁 중이거나 체력이 낮으면 50골드 고집 대신 20골드까지 리롤.
- 5스테이지에 7장 미만인 저코스트 리롤은 레벨업으로 전환. 7~8장이면 한 스테이지 더 기다리되 6스테이지부터는 인원수를 늘린다.
- 안정적인 상황에서 이자 구간을 깨는 저효율 구매를 억제. 합성·전력 충원·주력 구매는 허용.
- 상대 상점·숨겨진 풀·미래 RNG를 평가에 읽지 않는다.

## 브라우저 입력

게임 루트에서 기본 우클릭 메뉴·글자 선택을 막고, 이미지의 브라우저 기본 드래그를 차단했다. 기물·아이템의 게임 드래그는 유지한다. 입력창·텍스트 영역·편집 가능한 요소는 입력과 텍스트 선택을 허용한다.

## 추가 UI 요청

- 5코스트 컷신은 필드 왼쪽 아래의 피해량 창 바로 위(12px 간격)에 표시한다. 같은 컨테이너에 묶어 창 높이가 바뀌어도 겹치지 않는다. 이미지 비율, 0.85초 표시 시간, 5초 재생 간격, 관전 시 해당 플레이어 기준은 유지한다. 클릭을 가로채지 않는다.
- 상점에 구매 즉시 합성 가능한 기물은 ★★ 2성 가능 / ★★★ 3성 가능 배지를 표시한다. 필드와 대기석을 합산하고 2성→3성 연쇄 합성도 계산한다. 구매·판매 후 즉시 갱신되며 이미 가진 3성을 2성 복사본으로 잘못 세지 않는다.
