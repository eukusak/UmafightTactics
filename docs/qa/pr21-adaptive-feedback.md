# PR21: 상황별 설명, 전략 AI와 전투 피드백

## 변경된 플레이

- 이번 경기의 증강으로 바뀐 스킬, 아이템, 영구 누적 스택을 해당 소유자의 상세 설명에 반영한다. 상점·기물 툴팁·장비 보관함·보상·관전에서도 동일한 설명을 사용한다. 도감의 기본 정의는 변경하지 않는다.
- 증강의 세 카드마다 무료 리롤을 1회 제공한다. 등급은 유지하고 해당 선택 창에서 본 증강은 다시 나오지 않는다. 횟수/기존 선택지는 저장되며 온라인 서버가 소유자와 단계·횟수를 검증한다. AI도 가장 좋은 카드를 남겨두고 나머지 카드를 리롤한다.
- 특성은 브론즈→실버→골드→보라→프리즘 계열로 단계가 구분되고, 단계 보석이 표시된다. 특성 상세 기물은 코스트순이며 별표로 희망 기물을 선택한다.
- 특성 단계가 새로 활성화되면 해당 기물 주위에 파동이 나오고, 특성을 선택하면 필드의 해당 기물을 계속 강조한다. 관전 대상을 바꾸면 이전 강조를 남기지 않는다.
- 2·3성 합성은 실제 합성 결과 기물 주위에 원형 파동과 별을 표시하고 서로 다른 상승음을 재생한다.
- TFT 예시의 경기장 중심·좌우 정보·하단 상점 구성을 유지하며 테두리, 단계 색상, 순위 초상화, 상점 초상화와 비용 표시를 다듬었다. 방송/채팅 요소는 포함하지 않는다.
- PR21의 기존 벤치 교환, 레벨별 상점 확률, 복제기 장비 도구 기능을 함께 포함한다.

## 타격감

명중 시점은 엔진의 DAMAGE 이벤트, 스킬 소리는 SKILL_EFFECT, 공격 준비 소리는 ATTACK_START를 따른다. 별도의 데미지 판정이나 임의의 지연은 넣지 않는다.

피격 섬광, 물리 타격선/마법·보호막 원형 파동, 방향성 파편, 최대 6px의 작은 그림 반동, 치명타 숫자의 확대·감속 상승을 추가했다. 공격·스킬 동작 자체는 중단하지 않는다. 치명타와 강한 고코스트 스킬은 70ms의 작은 전투 카메라 흔들림을 사용하며 최소 350ms 간격을 둔다. 피격마다 75ms의 중복 제한과 동시 이펙트 상한을 적용해 다수 전투를 읽을 수 있게 했다.

효과음은 근접/원거리 공격, 명중, 물리/마법/지원 스킬, 증강 선택, 2/3성 합성을 구분한 자체 Web Audio 합성음이다. 캐릭터별 미세 피치 변형, 최대 16 동시 음성, 유형별 재생 간격 제한을 사용한다. 음소거와 효과음 볼륨에 연결되며 장치 오류가 게임 명령을 실패시키지 않는다. 관전 전환·건너뛰기로 과거 소리가 한꺼번에 재생되지 않는다.

OS/브라우저의 prefers-reduced-motion에서는 새 카메라 흔들림·피격 반동·숫자 이동 및 CSS 파동 애니메이션을 끈다. 게임 전체를 멈추는 히트스톱은 멀티플레이 시계/판정에 영향을 주므로 적용하지 않았다.

참고:
- [Lab Zero의 GDC 발표: Fluid and Powerful Animation within Frame Restrictions](https://media.gdcvault.com/GDC2014/Presentations/Cartwright_Muriel_Animation_Bootcamp_Fluid.pdf): Skullgirls, Street Fighter III, Guilty Gear 등의 키 포즈·anticipation·overshoot·명중 강조 사례. 이 게임에서는 기존 4프레임 아트를 유지하면서 명중 순간의 표현에 적용했다.
- [Epic Games: Camera Shakes](https://dev.epicgames.com/documentation/unreal-engine/camera-shakes-in-unreal-engine): 흔들림의 진폭·지속 시간·중첩 제어 원칙을 참고했다. Phaser 구현이며 Unreal 코드를 사용하지 않는다.
- [Designing Game Feel: A Survey](https://arxiv.org/abs/2011.09201): 피드백의 조합과 플레이 감각에 관한 연구. 객관적인 타격감 우월성을 증명한 사용자 실험은 아니다.

## AI 판단

실제 145명 기물 스킬과 전체 아이템·증강·특성 효과를 읽는 공통 평가기를 추가했다. 44개 효과 종류에 대해 크기·트리거·대상·범위·역할·마나 회전·물리/마법 비중을 평가한다. 장비 수 조건, 영구 누적 스택, 영웅 증강, 상징 중복과 특성 문턱을 편성/장비/증강 선택에 반영한다.

보유 기물·아이템과 공개된 상대 필드에 따라 캐리 계획을 다시 평가하고, 구매로 전력 상승이 생기면 덱과 배치를 갱신한다. 투자한 덱이 매 라운드 불필요하게 바뀌지 않도록 기존 투자 가중치는 유지한다. 더 강한 같은 역할의 장비 수용 기물이 실제 필드에 준비된 경우에만 벤치의 임시 장비 보유자를 판매해 장비를 옮긴다. 고립·인접 조건은 실제 육각 거리로 판단한다.

상대의 공개 기물·장비·증강으로 전력과 배치를 판단한다. 상대 상점·벤치·공유 풀의 숨겨진 재고·미래 RNG를 전략 입력으로 읽지 않는다. 기계학습 모델을 훈련한 것이 아니라 정의 기반 휴리스틱을 개선한 것이다.

참고:
- [Riot: Hextech Augments overview](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/gizmos-gadgets-set-mechanic-overview-hextech-augments/): 증강과 경제·편성·배치의 결합.
- [Riot: Augments, Augmented](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/augments-augmented/): 정찰과 증강에 따른 전략 변화.
- [Riot: Roles Revamped & Item Changes](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/roles-revamped-and-item-changes/): 역할·피해 유형과 장비 선택.
- [Riot: Dragonlands Learnings](https://teamfighttactics.leagueoflegends.com/en-sg/news/dev/dev-teamfight-tactics-dragonlands-learnings/): 유연한 조합과 전략 다양성. 역사적 설계 참고이며 최신 TFT와 완전히 같은 AI라는 의미는 아니다.

## 밸런스 검토

scripts/audit-roster-matchups.ts로 145명 × 3성급 × 시드 3개 × 좌우 교환, 변경 전/후 각각 2,610전을 실행했다. 같은 코스트·역할의 상대를 우선하며 동일한 보조 기물, 장비 없음/역할 장비 조건을 사용했다. 후보 6명은 12시드 × 3성급 × 양방향, 전/후 각각 432전을 추가 비교했다. 자연 특성이 유지되는 제한된 3대3 진단이다.

| 기물 | powerScale 전→후 | 변경 |
|---|---|---|
| 티엠 오페라 오 | 0.97→1.10 | 스킬 보호막 강화 |
| 심볼리 루돌프 | 0.97→0.92 | 스킬 피해 소폭 하향 |
| 아그네스 디지털 | 0.98→1.06 | 스킬 피해 강화 |
| 아그네스 타키온 | 0.98→0.93 | 스킬 피해 하향, 공격속도 버프 유지 |
| 그란 알레그리아 | 0.97→1.07 | 스킬 피해 강화 |

메이쇼 도토는 추가 표본에서 초기 약세 판단이 유지되지 않아 조정하지 않았다. 이 비교에서 모든 기물의 승률을 50%에 맞추지는 않았다. 디지털의 2성 조건은 조정 후에도 약세가 남고, 타키온의 2성 승률도 같은 표본에서는 변하지 않았다. 이를 전반적인 균형 달성이나 인간 상대 승률 향상의 증거로 해석하면 안 된다.

GitHub CI의 기존 200경기(시즌별 40)는 5개 시즌 작업으로 나눠 상세 AI 평가가 단일 검증 작업의 시간을 독점하지 않게 했다. 검사 수는 줄이지 않았다.

5시즌 × 동일 시드 2개, 전/후 각각 10회의 전체 AI 경기도 실행했다. 모든 시즌에서 종료와 공유 풀 보존을 확인했다. 시즌별 2경기는 프로필별 승률을 단정하기에 적다.

## 검증

타입 검사·린트·프로덕션 빌드, 단위 테스트 567개, 서버 시작 검사 9개, 엄격 자산 검사 514개가 통과했다. 브라우저 검사의 최종 결과는 PR 본문에 기록한다. 새 단위 검사는 증강별 설명·소유자 분리, AI 조건 평가·계획 변경·장비 이관, 리롤 슬롯/저장/서버 검증, 피격 효과 강도와 동작 줄이기, 수치 변경의 모션 호환성을 포함한다. 브라우저는 카드별 리롤/복원, 특성 별표/정렬/활성화/관전 강조 해제, 실제 기물 합성 효과, 전투 효과음과 음소거, 기존 배치·장비·관전 기능을 검사한다.

기물 데이터 해시가 바뀌므로 이전 버전의 진행 중 저장은 기존의 ROSTER_MISMATCH 보호 규칙에 따라 재개되지 않는다. 새 버전에서 시작한 경기의 리롤과 누적 효과는 정상 저장/복원한다.
