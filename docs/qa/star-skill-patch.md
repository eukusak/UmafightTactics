# 성급별 스킬 성장과 전투 상대 표시

기준: PR19 병합 커밋 a9c40bb5eab7b43d8c4b505139948250e59d380a.

## 문제와 변경

피해·고정 회복·고정 보호막에는 이미 성급 배율이 있었지만 상세 설명은 항상 1성 값이었다. 능력치 버프·비율 회복·마나 지원은 성장하지 않았으며 일반 스킬 피해에는 주문력이 반영되지 않았다.

- 피해·고정 회복·고정 보호막: 기존 성급 배율 × 현재 주문력/100. 물리 스킬도 주문력으로 스킬 계수가 증가하고 방어력으로 감소한다. 평타와 아이템 PROC_DAMAGE 경로는 이 배율을 사용하지 않는다.
- 지원 성장: 1성 1배, 2성 1.2배, 3성은 1~3코 1.5배 / 4코 1.8배 / 5코 2.2배. 양수 능력치 버프·중첩 체력·비율 회복·마나 지원·방어력 감소 등에 적용한다.
- 비율 회복/보호막은 대상 최대 체력의 성급 성장이 이미 적용되므로 주문력까지 곱하지 않는다. 회복 계수 75%, 보호막 계수 100%, 피해 감소/저항 감소 50%, 마나 지원 30(최대 마나 비율은 30%), 양수 능력치 비율 버프 150%의 상한을 둔다. 기존 원본 값이 상한을 넘으면 원본 값은 유지한다.
- 제어 시간·음수 능력치 디버프·공격 범위·대상 수·모션 타이밍은 유지한다. 무한 제어를 만드는 일괄 배율을 피한다.
- 상세창·도감·기물 툴팁에 1/2/3성 표를 표시한다. 상세창은 장비 주문력, 전투 중 현재 주문력 및 해당 캐릭터의 스킬 변형 증강을 반영한다. 전투 전 특성/증강 능력치 보너스는 전투가 시작된 후 현재 능력치에 반영된다. 원본 설명에는 1성/주문력 100/증강 전 기준을 명시한다.
- 표는 대상당 각 타격의 피해/회복/보호막이다. 같은 타격은 횟수를 함께 표시하며 방어력·치명타·격리 보너스·특성 증폭·회복 감소 이전 값이다.
- 전투 필드 상단에 VS 상대 이름을 표시한다. 관전하면 관전자의 실제 상대를 표시하며 PvE는 몬스터 이름을 사용한다. 첫 프레임에 양쪽 플레이어 ID를 보관하여 빈 필드 전투에서도 이름을 표시한다. 예전 녹화는 기물 ID로 복원한다.

## 코스트와 성급 차이

고정 수치의 성급 배율은 1성 1배 / 2성 1.45배 / 3성 1~3코 2.2배, 4코 3.6배, 5코 6배를 유지한다. 기본 스킬 계수는 코스트별 1 / 1.14 / 1.32 / 1.56 / 1.9이다. 체력·공격력 성급 배율도 기존 1 / 1.8 / 3.24를 유지한다.

같은 캐릭터 스킬 구성과 power 백분위 50%를 고정한 comet_fall 비교(주문력 100, 방어력 적용 전):

| 코스트 | 1성 | 2성 | 3성 |
| --- | ---: | ---: | ---: |
| 1 | 243 | 352.35 | 534.6 |
| 2 | 276 | 400.2 | 607.2 |
| 3 | 321 | 465.45 | 706.2 |
| 4 | 379 | 549.55 | 1,364.4 |
| 5 | 461 | 668.45 | 2,766 |

실제 트윈 터보의 공격속도 지원은 30% → 36% → 45%, 마루젠스키(4코)는 37.2% → 44.64% → 66.96%로 성장한다. 보호막/지원 키트의 동일 코스트 비교와 145명 전체 수치는 star-scaling-audit.json에 있다. 이것은 동일 성급의 기본 성능 차이이며, 서로 다른 성급·아이템·조합에서 고코스트가 무조건 이긴다는 뜻은 아니다.

TFT에서도 챔피언별 성급에 따른 스킬 수치 차이를 둔다. 공식 패치 예시: https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/teamfight-tactics-patch-12-14-notes/ . 본 게임의 독자적인 성급·코스트 곡선이며 TFT의 현재 모든 캐릭터 계수와 동일하다고 주장하지 않는다.
