# PR 6 재개 검증

초상화 마지막 10명은 `ab557e769c406fa9555b5e01ccbf65f6254bbd6e`에서 저장 완료했다. 로컬 Git 트리와 원격 생성 트리 SHA가 `30b13f9e3354a909e7c4a46a96cf9cb135be0416`으로 일치한다. 동시 작업 batch-20의 원본과 런타임 5명을 보존했다.

이번 후속 변경은 PvE 전신 5종, UI 폰트/도트 장식, 도달 가능한 공격 위치 선택이다. 다른 기물에 둘러싸인 빈 공격 칸을 고르던 문제를 BFS 이동 거리로 수정해 접근 가능한 측면으로 우회한다. 목적지 선택이 달라져 전투 결과에 영향을 줄 수 있다.

## 검증

- 전체 테스트 146개 통과: 온라인 8인, 저장 복구, 공유 풀, 전투·매치와 신규 경로 회귀 3개 포함.
- ESLint 및 TypeScript + Vite 프로덕션 빌드 통과. 기존 Phaser 큰 청크 경고 유지.
- 전체 아트 검사 369/514, 규격 불일치 0. 누락 145개는 전부 캐릭터 전투 시트이며 엄격 아트 완료 기준은 아직 충족하지 못한다.
- 초상화 batch-2001 10개: 원본 해시, 256×256 RGBA, 실제 투명도, 최소 6px 여백 및 등록 검사.
- 신규 PvE 전신 5개: 원본/런타임 해시, 512×512 RGBA, 투명도, y=440 발 앵커 및 등록 검사. 밝고 어두운 배경 육안 검수.
- In-app Chromium 1280×720: 타이틀→로비→드래프트→자동 배치→PvE 1-1, 1-2 클리어→1-3 보급 로봇 전투 표시·이동·공격 확인. 경고/오류 로그 0건.
- 도감 DOM 이미지 145개 모두 로드, 깨진 이미지 0개, 가로 넘침 없음. 타이틀/도감/전투 스크린샷 저장.
- Windows의 POSIX mode 비트 제한 때문에 저장 복구 테스트에서 0600 단언만 POSIX로 한정했다. Windows에서도 파일 생성·교체·복원·손상 보존 검사는 그대로 실행한다.

## 남은 제작

실제 Cubism 모델 0/145명 및 PvE 0/5종. 스페셜 위크부터 한 명씩 진행하되 현재는 부분 원화 5개이며 조립·추가 분리·리깅이 필요하다. 이 환경의 표준 설치 경로에서 Cubism Editor/컴파일 도구를 찾지 못했고 별도 환경 경로를 사용자에게 요청했다. Phaser Rope 모션이나 정적 PNG를 Live2D 완료로 세지 않는다.

TFT와 같은 공유 풀·경제·육각 배치·자동 전투·8인 라운드 구조를 갖추었으나 Riot 라이브 세트의 모든 콘텐츠·수치·내부 판정과 완전히 동일하다고 검증한 것은 아니다. 외부 배포는 수행하지 않았다.
