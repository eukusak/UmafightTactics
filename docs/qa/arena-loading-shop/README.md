# 경기장 이미지와 상점 슬롯 표시 개선

기준: PR14 머지 커밋 `9cf7bae43b1f5168e4a34353946892c21ba75c45`.

## 확인한 원인과 수정

- 정적 서버가 파일명이 고정된 PNG까지 1년 immutable 캐시로 응답했습니다. 특히 모션 시트가 128px에서 256px 셀로 바뀐 뒤 예전 파일이 남으면 새 좌표로 예전 그림을 잘라 읽게 됩니다. 빌드마다 그림 URL에 버전을 붙여 이미 저장된 무버전 캐시도 우회합니다. 무버전 파일은 재검증하도록 하고, 해시가 있는 번들/명시적으로 버전이 붙은 자산만 장기 캐시합니다.
- 경기장 CSS background는 로딩·디코딩 실패를 처리하지 않았습니다. 디코딩이 끝난 이미지만 표시하고 전환 중에는 직전 배경을 유지합니다. 초기 로딩 실패에는 기본 잔디 배경을 사용하며, 8초 제한·최대 3회 요청 후 다시 불러오기 버튼을 제공합니다. 오래된 경기장 요청은 전환/언마운트 시 취소하여 최신 배경을 덮어쓰지 않습니다.
- 경기장은 전체 프레임을 필드에 맞춰 표시합니다. `cover` 방식으로 가장자리를 잘라내지 않으며 배치 칸 투영은 유지합니다.
- 상점 CSS의 고정 5열 때문에 확장 스카우팅의 6번째 칸이 새 행으로 내려갔습니다. 실제 슬롯 수에 맞춰 열을 생성하고 최소 너비 제한을 없애 6칸을 같은 줄에 표시합니다. 구매 후 빈 칸도 같은 위치를 유지합니다.

## 검증

- 이미지 버전·네트워크 실패·디코딩 실패·타임아웃·취소·재사용 및 기존 배치 좌표: 9개 통과.
- 실제 프로덕션 시작 경로 9개 통과. 각 HTTP 서버에서 무버전 PNG 재검증 및 버전 PNG 장기 캐시를 확인했습니다.
- 고의적인 1회 네트워크 실패 후 복구, 지속 실패 시 대체 배경과 수동 복구, 데스크톱/모바일 배경 전체 영역, 상점 6칸 한 줄 및 6번째 칸 구매: 브라우저 6개 통과.
- 타입 검사·린트·프로덕션 빌드 통과. 전체 브라우저 회귀 검사는 PR 설명에 최종 결과를 기록합니다.
