# 초상화·기물 비교 자료

145명을 검토해 선택한 54명의 24프레임 이미지 반영본입니다. 각 행은 초상화, 기존 기물, 수정 후 대기, 수정 후 스킬 순서입니다. 유지 대상 91명과 초상화 원본은 변경하지 않았습니다.

## 검증 기록

- 전체 단위 테스트 351개, 타입 검사·린트·프로덕션 빌드 통과.
- 엄격한 아트 검사: 514/514 자산, 누락·규격 불일치 없음.
- 업로드 직전 외형·기존 아트 이력·프레임 검증 3개 파일, 6개 테스트 재통과.
- 로컬 브라우저 검사 결과 파일은 passed이며 실패 목록은 비어 있습니다. 이번 원격 커밋의 CI 결과는 GitHub Actions에서 별도로 확인합니다.

## 추가 세부 보정 기록

아래 6명의 추가 세부 보정을 완료했습니다. 초상화와 각 24포즈를 중립 배경에서 대조하고 실제 투명 알파를 검사한 뒤 게임용 512×768 시트로 다시 패킹했습니다. 시자리오는 후보에 남아 있던 주황색 눈을 추가 편집하여 모든 열린 눈을 보라색으로 통일했습니다.

| 캐릭터 | 완료한 보정 |
| --- | --- |
| 뱀부 메모리 | 초상화의 흰 중앙 앞머리 복원 |
| 원더 어큐트 | 모든 포즈의 가는 둥근 안경 |
| 시자리오 | 초상화 기준 양쪽 눈을 같은 연보라색으로 보정 |
| 애스턴 마짱 | 옆 포니테일 실루엣 강화 |
| 야마닌 제퍼 | 눈 색을 따뜻한 갈색으로 보정 |
| 히시 미라클 | 눈 색을 옅은 청록색으로 보정 |

6명의 원본 생성 이력은 유지하고 `generation.json`의 `detailRevision`에 실제 후속 프롬프트와 참조 커밋을 기록했습니다. 현재 생성 지침과 검토 사유도 흰 앞머리·양쪽 보라색 눈 등 최종 초상화 기준으로 정정했습니다. 원본 프롬프트의 잘못된 지시는 이력으로만 남깁니다.

최종 게임용 크기 검수에서 애스턴 마짱의 4행 2열 이펙트가 옆 프레임으로 번지는 부분을 발견해 길이를 줄였습니다. 24포즈와 실제 알파를 다시 확인하고 비교 자료를 갱신했습니다.
