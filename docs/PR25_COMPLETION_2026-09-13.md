# PR25 이미지·전투 후속 패치

기준: PR25 45aefe8c 및 사용자 제공 RACE_PLAN_CODEX_SPEC_v2.md. 원본 문서와 저장소 문서는 줄바꿈을 정규화한 뒤 동일함을 확인했다.

## 이미지 및 연출

imagegen으로 배경 3종(1920×1080), 라스트 3F 배너(960×180), 출발 게이트·승부처 링·라스트 3F VFX 시트 3종(1920×192, 10프레임)을 제작했다. 생성 후에는 크기·프레임 배치만 기계적으로 처리했다. 원본 프롬프트와 소스/최종 SHA-256은 [provenance.json](art-source/race-plan/provenance.json)에 보관한다.

선택창·출주표·전투 HUD와 Phaser 재생기에 연결했다. VFX는 출주마 주변에만 짧게 재생되며, 모션 줄이기 설정에서는 확대/반복을 줄인다. 이미지 요청 실패 시 바탕색과 도형 폴백을 유지한다. 기존 21종 SVG 아이콘과 캐릭터 모션은 유지한다.

## 전투 및 사용성 수정

- 지구력 스택이 같은 오라를 덮어써 6중첩도 1중첩 성능이 되던 오류를 노드별 누적 수치 갱신으로 수정했다.
- 한 번의 공격으로 여러 진행도 경계를 넘으면 각 페이즈를 순서대로 한 번씩 처리한다. 승부처 보상 누락을 방지한다.
- 장거리 승부수의 라스트 3F 지구력 비례 AD/AP 보상과 오버타임 이후 레이스 전용 스택 증가 중단을 반영했다.
- 관전 프레임을 생성하지 않는 AI도 자기 전투의 스킬 횟수·초반 전열 손실·승부처 적 전열 체력을 작전 선택에 사용한다.
- 진행도·출주마 자원을 전투 스냅샷에 담아 관전과 재생에서 같은 정보를 표시한다. 전투 요약에 레이스 발동 로그 탭을 추가했다.
- 선택창 키보드 포커스 유지, 작은 화면 줄바꿈, 로컬 선택 타이머/일시정지/자동 선택, 확정 도장 연출을 추가했다. 온라인은 서버 마감 시각을 표시한다.
- 공격·피격·스킬 게인을 0.11→0.16(약 +3.25dB)으로 올리고 마스터 컴프레서로 동시 발음 피크를 제어한다. 기존 음소거와 사용자 음량 설정을 따른다. 레이스 전용 합성 효과음 9종을 추가했다.

## 밸런스 검증 범위

PR25의 코스트 스탯·상점 확률·3성 배율은 유지했다. 이번 수정은 실제 누락된 레이스 효과와 AI 입력을 바로잡는다. 초기 250매치와 최종 재측정은 동일한 대조군이 아니므로 차이를 이번 패치의 인과 효과로 해석하지 않는다.

90노드 구조 검사는 오류 0건이다. [아이템 환산 진단](generated/RACE_PLAN_BUDGET_REVIEW.md)은 78개 검토 표시를 남긴다. 명세 예시 수치와 좁은 IE 예산 범위가 일관되게 맞지 않고, 지원 대상·마나 회전·조건부 효과는 단순 환산이 불가능하므로 엄격한 IE 통과 또는 90개 노드의 동일 승률을 주장하지 않는다. 기본 audit는 구조 오류를 실패 처리하고 추정 경고를 출력한다. --strict-ie는 별도 튜닝용이다.

## 검증 진행

타입 검사·린트·데이터 검증·프로덕션 빌드, 엄격 아트 검사 521/521 및 선택창/전투 음향 브라우저 검사 13개 통과. 전체 단위 테스트, 양쪽 화면 크기의 브라우저 회귀 검사, 시즌별 100매치(총 500매치) 재측정은 실행 중이며 결과를 이 문서에 추가한다.
