# 각질·스킬 원화 추가 패치

## 범위

PR #12의 아이템·145명 스킬 개편에 이어, 4명의 스킬 원화 16프레임과 각질 12명, 5개 특성 수치 및 이벤트 버프 엔진을 수정했다. 145명 전체를 재생성하지 않았다.

| 캐릭터 | 스킬 원화 4프레임 |
|---|---|
| 사일런스 스즈카 | 민트 충전 → 양손 전개 → 빔 유지 → 회수 |
| 오구리 캡 | 별 충전 → 머리 위 준비 → 하강 혜성 → 회수 |
| 토카이 테이오 | 조준 → 첫 발 → 삼연사 → 석궁 회수 |
| 라이스 샤워 | 장미 준비 → 손 뻗기 → 흡수·방어 → 경계 자세 |

내장 image_gen으로 생성했다. 실제 RGBA 투명 원본, 최종 프롬프트, 육안 검토, 크롭 좌표와 SHA-256을 [원화 기록](art-source/motions/skill-revisions-2026-09-10/)에 보관한다. RGB 배경이 남은 시안은 채택하지 않았다. 각 512×768 시트의 12–15번 프레임만 변경했고 나머지 20개는 원본 픽셀 해시가 같다. 별도 VFX 타격 판정은 기존 스킬 이벤트와 타임라인을 사용한다. 라이스의 방어막 그림은 기존 피해 감소를 표현하며 새 보호막 수치를 만들지 않는다.

패킹: Sharp가 설치된 Node 환경에서 `node scripts/pack-skill-revision.mjs silence_suzuka oguri_cap tokai_teio rice_shower`. 원본 커밋 ccd64939가 로컬 Git에 있어야 한다. 패커는 원본 알파를 유지하고 리사이즈·시트 배치만 수행하며 배경 제거 또는 원화 드로잉을 하지 않는다. 다른 모션 행이 원본 이후 변경되었다면 덮어쓰기를 거부한다.

## 각질 조사

[UmaRogue](https://github.com/eukusak/UmaRogue)의 경주 원본 SQLite(6413행), 커밋 b53aab53a96626187bc9877dacd4a0cab5d94275, Git blob e0aee26ca7353d897e96a8da8bd16c277428eef6을 사용했다. [전체 145명 근거](../src/data/manual/running-style-evidence.json)와 [12명 교정](../src/data/manual/running-style-corrections.json)을 분리했다.

[JRA 용어 사전](https://www.jra.go.jp/kouza/yougo/c10180_list.html)의 각질 개념과 [골드 쉽 2015 천황상](https://www.jra.go.jp/datafile/seiseki/g1/haruten/result/haruten2015.html), [타이키 셔틀 1998 마일 CS](https://www.jra.go.jp/datafile/seiseki/g1/mile/result/mile1998.html)도 참고했다. 각질은 경기별 전술이며 영구 고정 능력이라는 뜻이 아니다.

분류는 공식 JRA 판정식이 아닌 감사 가능한 추정이다. 6두 이상, 유효 통과 위치 2개 이상인 평지 경주에서 초반 두 지점 평균을 사용했다. 평균 1.5위 이내는 도주, 나머지는 (평균 순위−1)/(출전두수−1)이 0.35 이하면 선행, 0.67 이하면 선입, 그 밖은 추입이다. 최소 8전·60% 지지에 더해 수작업으로 검토했다. 결승 순위를 초반 위치로 쓰지 않았다. 마야노 탑건·아스톤 마짱·탭 댄스 시티처럼 전술 변동이 큰 사례는 자동 변경하지 않았다.

- 골드 쉽: 선입 → 추입(18/27).
- 도주 → 선행: 타이키 셔틀(11/12), 비와 하야히데(12/16), 카렌짱(12/16), 니시노 플라워(11/16), 메지로 아르당(10/14), 노스 플라이트(8/11), 홋코 타루마에(30/36), 데어링 하트(24/26), 젠틸돈나(11/17), 빌리브(18/27), 라인 크라프트(9/13).

각질 교정으로 시즌 편성을 재생성하되 캐릭터별로 작성한 스킬 몸동작 유형은 유지한다. 자동 편성에 따른 비용 변경은 기존 생성 파이프라인으로 처리하고 바뀐 스킬 서명을 검토 기록과 동기화했다.

## 전투 수정과 수치

처치·시전 같은 이벤트형 지속 효과를 엔진이 건너뛰던 문제를 수정했다. 이벤트 발생 후 조건을 소비해 지정 시간 동안 유지하며, 재발동은 중첩 대신 지속시간을 갱신한다. 체력·대상 체력 등의 지속 조건은 매 틱 유지한다. 선입 처치 효과의 실제 발동, 중복 갱신, 만료를 회귀 검사한다.

| 특성 | 변경 |
|---|---|
| 도주 | 4/6단계 공속 25/45% → 22/38%; 2단계 유지 |
| 선행 | 피해 증폭의 체력 조건 70% → 60% |
| 선입 | 상시 치명타 5/10/15% 추가; 처치 후 추가 치명타 10/20/35% → 10/15/25%; 피해 증폭 유지 |
| 추입 | 6단계 피해 증폭 35% → 30%, 처치 마나 20 → 15 |
| 불굴의 맹세 | 단계당 보호막 10% → 8% |

44개 특성의 각 구간을 동일한 2성 기물 보드에 추가하고 좌우를 바꾸는 고정 시드 실험을 실시했다. [수정 전](qa/trait-calibration-before.json), [이벤트 오류 수정 후](qa/trait-calibration-event-fix.json), [최종](qa/trait-calibration-after.json). 이는 한쪽만 특성을 더했을 때의 증가분이며 실제 조합 승률이 아니다. 경제 효과는 아래 캠페인 검증으로 보완한다. 선입 6단계의 평균 잔여 HP 차이는 0 → 1170, 불굴의 맹세 7단계는 2430 → 2111로 변했다. 다른 동시 특성도 바뀌므로 개별 계수 하나의 순수 인과 효과로 해석하지 않는다.

## 시즌 매치 검증

각 시즌 20매치, 총 100매치·13066전투(기준 시드 20260907). 무승부 221회(1.69%), 모든 공유 풀 보존 정상. 7개 AI 프로필 평균 순위는 전 시즌 목표 2.5–6.5 범위다.

탈락자 보드는 정산 시 지워지므로 정산 직전 전장 특성을 저장하도록 집계기를 수정했다. 상위 4명 표가 승자 보드만 보던 문제를 제거했고 시즌마다 정확히 80개의 상위 4위 표본을 집계했다. 상징과 증강 부여 특성도 포함한다. 특성별 활성 보드 수와 조건부 상위 4위/우승 횟수는 각 시즌 JSON의 traitOutcomes에 기록한다.

| 각질 | 활성 보드 | 상위 4위 | 조건부 진입률 |
|---|---:|---:|---:|
| 도주 | 550 | 269 | 48.9% |
| 선행 | 660 | 333 | 50.5% |
| 선입 | 396 | 224 | 56.6% |
| 추입 | 205 | 117 | 57.1% |

S2 별빛 아리아 35%, S5 왕관의 계승자 35%·선행 30%의 주력 특성 우승 점유율 경고는 남았다. 이는 단독 승률이 아니며 특성 분포·기물 비용·AI 편성과 표본 크기의 영향을 받는다. 독립 전투에서 압도적이지 않은 특성을 경고 숫자만 없애려고 추가 하향하지 않았다. 밸런스 완전 동등성이나 TFT 동일성을 인증하는 결과는 아니다. 이전 200매치 표와 이번 100매치는 표본 수가 다르므로 직접 개선율로 비교하지 않는다.
