# 캐릭터 스킬·모션 연결

2026-09-09: 캐릭터 145명과 PvE 5종의 기본 모션을 모두 통합했다. 캐릭터마다 6개 행동 × 4포즈를 사용한다. 캐릭터 스킬은 기존 동작 계열 8종을 보존하면서 24가지 전술 변형을 배정했다. 145가지 완전히 다른 알고리즘이라는 의미는 아니다.

## 적용한 변형

| 기본 동작 | 전술 변형 | 대표 캐릭터 |
|---|---|---|
| 직선 돌파 | 방어 감소 / 자기 보호막 / 화상 | 스페셜 위크 / 타마모 크로스 / 골드 쉽 |
| 광역 폭발 | 마법 저항 감소 / 지연 재폭발 / 화상·회복 감소 | 오구리 캡 / 사일런스 스즈카 / 다이와 스칼렛 |
| 3연사 | 후속 공격속도 / 방어 관통 / 자기 회복 | 토카이 테이오 / 다이이치 루비 / 아그네스 디지털 |
| 팀 오라 | 전체 보호막 / 회복 3파동 / 이동속도 | 세이운 스카이 / 세자리오 / 키타산 블랙 |
| 제어 | 기절·이동 둔화 / 짧은 기절·공속 감소 / 침묵 | 히시 아마존 / 슈퍼 크릭 / 에어 메사이아 |
| 회복 | 보호막 / 잃은 체력 추가 회복 / 분할 회복 | 신코 윈디 / 킹 헤일로 / 이쿠노 딕터스 |
| 방벽 | 군중 제어 면역 / 반격 파동 / 자기 재생 | 젠노 롭 로이 / 티엠 오페라 오 / 라이스 샤워 |
| 결정타 | 방어 파쇄 / 자기 회복 / 최대 체력 비례 추가 피해 | 드림 저니 / 부에나 비스타 / 듀랜달 |

`skill-variants.ts`의 명시적 캐릭터 그룹과 기본 변형이 최종 `SkillDef`를 만든다. `all-units.json`에는 145명 각각의 최종 효과와 설명이 저장된다. 이름이나 색상만 바꾸는 방식이 아니라 대상의 상태, 반복 횟수, 후속 발동, 회복·보호막 등이 전투 결과를 바꾼다. 신규 밸런스이며 경쟁전 승률이 검증됐다는 뜻은 아니다.

## 실행과 화면

1. `CAST`가 준비 모션을 시작한다. 기본 스킬은 준비 0.35초, 3연사는 즉시 첫 발사한다.
2. `skillTimeline()`이 각 효과를 50ms 전투 틱에 맞춘다. 3연사는 0 / 0.20 / 0.35초, 분할 회복은 일반적으로 0.35 / 0.65 / 0.95초에 발동한다. 원래 지정한 1/6초 등의 간격은 다음 전투 틱으로 올림한다.
3. 엔진이 실제 효과를 처리한 시점에 `SKILL_EFFECT`로 대상 목록과 효과 종류를 기록한다. 이펙트는 이 이벤트를 따라간다. 모션 미리보기도 같은 시간표를 사용한다.
4. 시전 및 후속 발동 중 기본 공격은 대기한다. 기절하면 남은 시전이 취소되고, 사망한 시전자의 대기 효과는 사라진다. 대상이 사망하거나 대상 지정 불가가 되면 원래 대상 규칙으로 다시 선택한다. 살아 있는 최초 목표는 유지한다.
5. 방어력·마법 저항 감소와 임시 치명타 강화는 만료 시간을 지킨다. 최종 승패를 포함한 이벤트는 프레임에 정확히 한 번 기록한다.

전투의 긴 경주명 표시는 짧은 전술명으로 바꾸고, 같은 대상의 동시 이펙트를 묶어 기물을 덜 가리게 했다. 전체 스킬명과 설명은 상세 정보에서 확인한다. Canvas와 WebGL 모두 일반 알파 합성을 사용한다.

## 원화 출처와 재검토

기본 동작·목표 방향·돌진 거리·소환 여부는 이번 변형에서 유지된다. 양팔을 펼친 오라에 회복 파동을 추가하는 등 몸 동작과 양립하는 부가 효과를 엔진에서 그린다. 기존 PNG를 다시 생성했다고 표시하지 않는다.

[호환성 검토 기록](art-source/motions/skill-choreography-review.json)에 이전 전체 스킬, 이전·현재 스킬 해시, 기존 PNG 해시, 변형별 검토 이유를 남겼다. 원본 생성 프롬프트와 생성 당시 스킬 해시는 보존한다. 현재 스킬이 또 바뀌면 해시 검사가 다시 실패한다. 새로운 무기, 이동, 소환 등 몸 동작을 바꾸는 수정은 별도 원화 작업이 필요하다.

## 확인 방법

시작하기 → 기물 모션 미리보기 → 캐릭터 선택 → 스킬. 시간 슬라이더, 방향 반전, 28기 동시 표시와 Canvas 호환 모드로 확인한다. 파동은 효과의 발동 시각을 보여준다.

공개 TFT 규칙의 적용 범위와 출처는 [규칙 비교](TFT_PARITY_AUDIT.md), 브라우저 및 회귀 검증은 [QA 기록](qa/SKILL_SYSTEMS_2026-09-09.md)을 참고한다.
