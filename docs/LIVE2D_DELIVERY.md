# 기물 애니메이션 납품 방식

2026-09-08 사용자 요청으로 **부위 리깅 대신 캐릭터별 스킬에 맞게 생성한 이미지 프레임을 재생하는 방식**으로 변경했다. 현재 구현, 실제 완료 수와 제작 절차는 [프레임 애니메이션](FRAME_ANIMATION.md)을 따른다.

기존 `docs/art-source/rigging/`의 부위 원화는 중단한 방식의 제작 기록이다. 현재 게임은 그 부품을 조립하거나 Cubism 모델을 로드하지 않는다. `.cmo3`, `.moc3`, `.model3.json`은 이번 프레임 방식의 납품 조건이 아니다.
